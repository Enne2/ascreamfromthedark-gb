# Obsolete test runners

Questi runner sono conservati come riferimento storico ma non sono supportati.
Usano percorsi ROM errati, vecchie API PyBoy, stride WRAM non aggiornati o
output assoluti esterni al repository.

La suite supportata è `make test`, basata su `validate_tiling_visual.py`,
`validate_static_screen.py` e `validate_rom_header.py`.
